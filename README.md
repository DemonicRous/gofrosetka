# ГофроСетка

Клиентский конструктор разделительных решёток из гофрокартона. Vue 3, Tailwind CSS 4, Canvas/CSS-визуализация. Сборка пригодна для GitHub Pages.

```bash
npm install
npm run dev
```

## PDF

В конструкторе нажмите «Сохранить PDF» и выберите страницы: вид сверху,
центрированная 3D-модель, чертежи полос, раскладка штампа или плоттера.
PDF формируется локально в браузере в альбомном A4. Для RODA страница
раскладки недоступна. Можно скачать любую непустую комбинацию страниц.
При экспорте из вкладки 3D сохраняются добавленные в ячейки продукты.
Размеры на чертежах указаны в миллиметрах; печатный масштаб не 1:1.

Проверки генератора: `scripts/test-pdf.mjs` (нужен пакет `@napi-rs/canvas`,
путь можно указать через `CANVAS_MODULE`). Для проверки реального WebGL
используется `scripts/test-pdf-browser.mjs` с локальным сервером на порту 5174,
Playwright (`PLAYWRIGHT_MODULE`) и установленным Edge. Тестовые PDF сохраняются
в игнорируемую папку `tmp/pdfs`.
